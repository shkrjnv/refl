# refl — темы, ачивки, косметика, профиль

Nov 24, 2026 · @Hara

Темы, ачивки, косметика профиля, карточки и компаньоны (docs/06) построены на одной модели разблокировок и на том же логе событий, что и обучение (docs/01, «Социальные функции и инструменты»). Ничто здесь не влияет на обучение: модель ученика, планировщик и контент не зависят от темы, рамки или ачивок.

Эталонные экраны: ProfileV2, Wardrobe (примерочная), Achievements, Deck (колода), ProfileOther, Frames на холсте дизайна (docs/08).

## Принципы

- **Награда только за результат,** а не за клики, время в приложении, входы или число заданий.
- **Ничего случайного.** Нет наборов, лутбоксов, «выпало». Награда, которую можно только «выкрутить», — механика игрового автомата; у детей она действует сильнее всего.
- **Ничего не покупается.** Нет внутренней валюты, магазина, платных ускорителей и «догнать за монеты». Если появится монетизация, она не продаёт ни косметику, ни прогресс.
- **Без сравнения учеников.** Нет XP-уровня, глобальных и недельных рейтингов, «топ-N». Уровень у нас один — CEFR.
- **Открытое не отбирается** (кроме ошибочной выдачи админом).

## Модель разблокировок

Одна сущность на всё, что можно открыть.

| Поле | Значение |
| --- | --- |
| kind | theme, companion, avatar, frame, background, title, effect |
| key | id пакета (слаг) |
| source | milestone, achievement или admin |

- **Получение — событие в логе** `unlock_granted` (kind, key, source, ссылка на веху или ачивку). Набор открытого у ученика — свёртка лога.
- **Открытое вехой или ачивкой не отбирается никогда.** Выданное админом админ может отозвать событием `unlock_revoked`, например при ошибочной выдаче.
- **Базовые вещи есть у всех** без события: три базовые темы, базовый компаньон, стартовые аватары, рамки ступеней уровня, базовый фон.
- **Выбор** — события: `theme_selected`, `companion_selected`, `cosmetic_selected` (слот, ключ). Выбрать можно только открытое.

**Кто пишет производные события.** `milestone_reached`, `achievement_earned` и `unlock_granted` вычисляются из лога и дописываются только сервером после синхронизации. Ключ уникален, поэтому повторное вычисление идемпотентно. Офлайн клиент может показать празднование сразу по своей свёртке, а сервер затем фиксирует событие; вычисление одно и то же, потому что это одно ядро.

**Уникальность и события админа.** Уникальны только производные события:

- `milestone_reached` — по (ученик, вид level или topic, ключ — уровень или id темы);
- `achievement_earned` — по (ученик, id ачивки, ступень);
- `unlock_granted` с источником milestone или achievement — по (ученик, kind, key).

Выдача и отзыв админом (`unlock_granted` с источником admin, `unlock_revoked`) не уникальны: админ может выдать снова после отзыва, текущее состояние — свёртка. Источник указывается ключом (вид и ключ вехи или id ачивки со ступенью), а не id события, поэтому повторное вычисление даёт тот же payload. События, которые пишет сервер: session_id пуст, client_ts = server_ts = время записи; события админа содержат id админа.

## Редкость

| Редкость | Что значит |
| --- | --- |
| Обычная | ранние вехи, первые ступени ачивок |
| Редкая | вехи A2–B1, средние ступени |
| Эпическая | B2, высокие ступени, события команды |
| Легендарная | C1, последние ступени, уникальные ачивки, особые выдачи админа |

Редкость — свойство предмета в контенте, она описывает трудность условия. Это не вероятность выпадения: случайности нет.

## Темы

Тема — это весь дизайн интерфейса: палитра, шрифты, иллюстрации, облик компаньонов, звуки и анимации. Как устроены токены и слоты, описано в docs/08.

- **Пакет темы:** токены, иллюстрации по слотам, звуки, анимации, облик каждого компаньона (отдельный спрайт-лист, docs/06). Новая тема — новый пакет, без изменения кода.
- **Доступ:**
  - три базовые темы есть у всех (docs/08): «Живая Студия» — основная, «Мир» — предлагается по умолчанию детям, «Студия» — строгая;
  - 5–10 простых тем ученик открывает ачивками;
  - кастомные темы (например, «Блоки», «Сцена») выдаёт админ.
- **«Блоки»:** вайб кубического мира, крупный пиксель, ощущение копания и строительства — да. Название, логотип, узнаваемые текстуры, персонажи, звуки и шрифты Minecraft — нет: всё своё. То же правило для любой темы «в духе» известной игры.
- **Проверки пакета темы при сборке:** контраст не ниже WCAG AA во всех состояниях, наличие всех токенов, облик для каждого существующего компаньона, шрифты покрывают нужные символы (docs/08).

## Косметика профиля

Пять слотов, как в «Примерочной».

| Слот | Что это | Откуда |
| --- | --- | --- |
| Аватар | иллюстрированный портрет из набора (компаньоны, персонажи refl) | стартовые у всех; остальные — вехи и ачивки |
| Рамка | детальная иллюстрированная рамка вокруг аватара | ступени уровня; ачивки; события и выдача админа |
| Фон | анимированная сцена за аватаром в шапке профиля | ачивки, события |
| Титул | короткая подпись рядом с именем («Укротитель артиклей») на uz/ru/en | ачивки, ступени ачивок |
| Эффект | лёгкая анимация вокруг аватара (искры, сияние) | высокие ступени и легендарные ачивки |

- **Предметы — контент:** ключ, слот, редкость, название и описание на uz/ru/en, иллюстрация, «как получить». Проверяются при сборке, как пакеты тем.
- **Одна иллюстрация на предмет.** Тема может дать свой вариант рамки или фона (слот с наследованием, docs/08), но не обязана: без варианта рисуется основной.
- **Анимация** фона и эффекта подчиняется правилам движения docs/08: выключается настройкой «Анимация фона» и системной «уменьшить движение».
- **Аватары — только из набора.** Загрузка своих фото — открытый вопрос (нужна модерация; у детей — нет).
- **Примерочная:** предпросмотр любого предмета, в том числе закрытого, с «как получить» и «как увидят другие». Надеть можно только открытое.

## Рамки

Рамка ступени показывает уровень ученика: чем выше уровень, тем она детальнее, у верхних появляется сияние.

| Ступень | Рамка | Редкость |
| --- | --- | --- |
| pre-A1 | Росток | обычная |
| A1 | Луговой венок | обычная |
| A2 | Иней | редкая |
| B1 | Сумеречный лавр | редкая |
| B2 | Аметистовые крылья (сияние) | эпическая |
| C1 | Солнечный венец (сияние, искры) | легендарная |

- **Ступень — веха уровня** `milestone_reached` (docs/06): рамка не понижается, когда что-то забылось.
- **Другие рамки** — за ачивки, события команды и от админа (`unlock_granted` с видом frame). Надетая другая рамка заменяет рамку ступени; уровень по-прежнему виден в профиле значком.
- Пока ученик ничего не выбрал, надета рамка текущей ступени; при новой вехе он получает новую автоматически. Отзыв надетой рамки возвращает рамку ступени.
- **Иллюстрации** — векторные (SVG) с анимацией на CSS, в одном стиле с эталонами с холста; детализация не ниже эталонов.

## Ачивки

**Определение ачивки** — условие над свёрткой лога. Поэтому новая ачивка выдаётся задним числом всем, кто её уже заслужил. Условия — именованные предикаты в ядре с параметрами; сама ачивка (предикат, параметры, ступени, название, описание на uz/ru/en, эмблема, награда) — контент. Новая ачивка на существующем предикате добавляется без кода.

**Ступени.** У ачивки может быть до шести ступеней (I–VI) с порогами и именами («Новичок», «Ученик», «Знаток», …). Каждая ступень — отдельное `achievement_earned` (id, ступень). Эмблема растёт со ступенью: обод, лавры, камень, крылья, сияние.

**Награда** — косметика (`unlock_granted` с источником achievement): фон, титул, рамка, эффект. Не у каждой ступени есть награда.

**Виды:**

| Вид | Условие | Что видит ученик |
| --- | --- | --- |
| Обычная | известно заранее | название, условие, прогресс «осталось N до IV», ступени |
| Секретная | реальное, результат обучения, нигде не раскрыто | до получения — только силуэт «?»; после — название и художественное описание, но не точное условие |
| Уникальная | первый в команде, кто достиг вехи | получает ровно один человек в команде; «первый» определяется порядком (server_ts, event_id); остальные видят «уже взял …» и следующую цель |

**Экран ачивок:** фильтры «В работе / Не взято / Взято / Все», разделы (грамматика, словарь, память, регулярность, команда, секретные, уникальные), сортировка «сначала близкие». У каждой — прогресс, точки ступеней, награда и доля учеников, у кого она есть («есть у 27%»). Доля описывает ачивку, а не человека; считается сервером раз в сутки.

**Видимость.** Ученик сам решает, какие полученные ачивки показаны в профиле (событие `achievement_visibility_set`). Новая ачивка у взрослого видна по умолчанию. У детей профиль по умолчанию закрыт (docs/01).

**Стартовый список:**

| Ачивка | Вид | Условие |
| --- | --- | --- |
| Первый шаг | обычная | первая освоенная KC |
| Тема закрыта | обычная | первая тема, где освоено ≥ 80% важности KC |
| Уровни A1 … C1 | обычная | веха уровня (docs/06) |
| Серия I–V | обычная, ступени | серия 7 / 30 / 60 / 120 / 365 дней с заморозкой |
| Вылечено I–IV | обычная, ступени | 1 / 10 / 25 / 50 заблуждений в статусе «вылечено» (docs/03) |
| Долгая память I–V | обычная, ступени | 20 / 60 / 150 / 300 / 500 KC в статусе «надолго» |
| Мастер грамматики I–IV | обычная, ступени | закрыто тем уровня: 5 A1 / 10 A2 / 10 B1 / 10 B2 |
| Хранитель слов I–VI | обычная, ступени | слов в долгой памяти: 250 / 750 / 1 500 / 3 000 / 5 000 / 8 000 (этап 3) |
| Книжный червь I–VI | обычная, ступени | прочитано текстов с пониманием ≥ 80%: 1 / 10 / 40 / 100 / 200 / 400 (этап 3) |
| Первый мок | обычная | первый полный мок IELTS (этап 6) |
| Встречный ветер | секретная | вылечено заблуждение, активное 21 день и дольше |
| Выше головы | секретная | уверенный верный ответ с вводом на задание KC на два уровня выше уровня ученика |
| Вернул | секретная | KC из статуса «забывается» снова «освоено» без подсказок |
| Точность | секретная | 5 сессий подряд без единой уверенной ошибки при ≥ 20 ответах в каждой |
| Первооткрыватель | уникальная | первый в команде, кто достиг уровня B1 (и отдельно B2, C1) |
| Хранитель темы | уникальная | первый в команде, кто закрыл тему |

Пороги стартовые; секретные условия в интерфейсе не публикуются, но лежат в контенте в git, как всё остальное.

## Карточки

Одна карточка — одна тема. Карточка — это способ показать закрытую тему, а не отдельная награда.

- **Получение:** тема закрыта, то есть `milestone_reached` с видом topic. Отдельного события нет: колода — свёртка лога.
- **Редкость = уровень темы:** A1 обычная, A2 необычная, B1 редкая, B2 эпическая, C1 легендарная.
- **Лицевая сторона:** иллюстрация, название темы, образное имя («Мост времени»), уровень. **Оборот:** правило коротко, пример ученика и вылеченная ошибка, если была.
- **Не сгорает:** если тема забывается, на карточке появляется «освежить», а карточка остаётся.
- **Не покупается, не обменивается, не выпадает.** Знания не передаются.
- **Витрина:** ученик выбирает до 5 карточек для профиля (событие `showcase_set`: вид cards, список ключей).
- Иллюстрации карточек — контент темы; без иллюстрации тема в колоду не попадает (проверка сборки).

## Подарки

Подарок — открытка к вехе друга: «поздравляю с B2».

- **Кто дарит кому:** взаимные друзья и участники одной команды. У ребёнка — только внутри команды, без текста; сообщение у взрослых — до 140 символов.
- **Повод — веха получателя** (уровень, закрытая тема, ачивка). Подарок без повода нельзя: это не валюта и не способ «прокачать» друга.
- **Набор подарков** — контент: иллюстрация, название, редкость. Подарок ничего не открывает и не влияет на обучение.
- **Хранение:** подарки — социальные данные, отдельная таблица (кто, кому, ключ подарка, повод, текст, время), а не лог обучения. Удаляются вместе с аккаунтом.
- **Безопасность:** получатель может скрыть подарок, заблокировать отправителя и пожаловаться (docs/01); у ребёнка подарки от взрослых вне команды невозможны.
- В профиле — сетка последних подарков с отправителем; видимость — как у профиля.

## Профиль

| Что | Сам ученик | Другие (профиль открыт) | Другие (профиль закрыт) |
| --- | --- | --- | --- |
| имя, команда, публичный код | да | да | имя и команда |
| аватар, рамка, фон, титул, эффект, уровень | да | да | нет |
| ачивки | все, с переключателем видимости | только выбранные | нет |
| карточки | вся колода | витрина | нет |
| подарки | все | да | нет |
| компаньон и глава | да | да | нет |
| статистика, ошибки, заметки, серия, время | да | никогда | никогда |

- **Кто видит:** private, team, friends, public — настройка `profile_visibility` (docs/01).
- **Чужой профиль рисуется в теме смотрящего:** ключи предметов берутся из лога владельца, а вариант рамки или фона, если тема его даёт, — из темы смотрящего.
- **Сравнения нет:** в чужом профиле нет кнопок «сравнить», рейтингов и процентилей.

## Чего нет и почему

| Чего нет | Почему |
| --- | --- |
| внутренняя валюта, магазин, «догнать за монеты» | покупка прогресса и игровой автомат |
| награды за ежедневный вход | награда за присутствие, а не за результат |
| XP-уровень, рейтинги, «топ-N» | дублирует CEFR и вводит сравнение учеников |
| ачивки за время и число просмотров | подталкивают «сидеть», а не учиться |
| наборы и случайные выпадения | механика игрового автомата |
| обмен карточками | карточка — это знание ученика |

## События и данные

| Событие | Поля |
| --- | --- |
| `milestone_reached` | веха: level (уровень CEFR) или topic (id KC темы) |
| `achievement_earned` | id ачивки, ступень |
| `achievement_visibility_set` | id ачивки, видна ли в профиле |
| `unlock_granted` | kind, ключ, источник: веха, ачивка (со ступенью) или админ (id админа) |
| `unlock_revoked` | kind, ключ, id админа |
| `theme_selected` | ключ темы |
| `companion_selected` | ключ компаньона |
| `cosmetic_selected` | слот (avatar, frame, background, title, effect), ключ |
| `showcase_set` | вид (cards), список ключей |

Уже в схеме с этапа 0.3: `milestone_reached`, `achievement_earned` (без ступени), `achievement_visibility_set`, `unlock_granted`, `unlock_revoked` (kind: theme, frame, companion), `theme_selected`, `companion_selected`. Новое: ступень в `achievement_earned`, новые kind, `cosmetic_selected`, `showcase_set`, таблица подарков. Вносятся в ядро вместе с правилом о неизвестных типах событий у старых клиентов.
