# Методика refl: от рефлексии к рефлексу

Nov 24, 2026 · @Hara

## Идея

refl не изобретает педагогику и не берёт одну методику целиком. Он собирает приёмы с самой сильной доказательной базой в один цикл и реализует каждый как механизм данных и планировщика, а не как совет учителю. Цикл общий для английского, японского и математики; различаются только задания.

Название цикла повторяет название платформы. **Рефлексия** — ученик думает о своём знании: делает попытку, объясняет себе правило, оценивает уверенность. **Рефлекс** — правило применяется автоматически и быстро. Обучение идёт от первого ко второму.

## 2. Представление: конкретное → наглядное → абстрактное

У задания и примера в объяснении есть поле **представление**: `concrete` (предметы, ситуация), `pictorial` (схема, полоса, линия времени), `abstract` (символьная запись).

- **Математика.** Новая тема начинается с конкретного и наглядного (полосы дробей, числовая ось — docs/10, «Визуальные примитивы») и переходит к символам. Планировщик для новой KC в фазе блока берёт задания по порядку представлений, если они есть; дальше — только абстрактные, наглядные остаются в объяснении.
- **Английский.** Наглядное — линия времени для времён глагола, картинка для предлогов места; для учеников 8–12 лет это основной вход в тему. Отдельная лестница представлений не нужна: представление — тег, по которому планировщик предпочитает наглядные задания младшим ученикам на новой теме.

## 3. Разбор с затуханием

Многошаговое задание (docs/10, «Многошаговые решения») умеет показывать первые s шагов уже решёнными. Ученик решает остальные. Затухание обратное: сначала решено всё, кроме последнего шага, потом — кроме двух последних, и так до самостоятельного решения.

**Уровень выбирается по модели, а не по номеру задания.** Полные разборы помогают новичку и мешают тому, кто уже умеет (эффект обратной экспертности). Поэтому:

| Mₖ | Уровень scaffold |
| --- | --- |
| < 0,3 | n − 1 шаг показан, решается последний |
| 0,3–0,5 | показана половина шагов |
| 0,5–0,7 | показан первый шаг |
| > 0,7 | без разбора |

Пороги — стартовые, настраиваются на симуляторе и микрорандомизацией на границах (docs/11, К5).

- **Математика:** шаги решения уравнения, задачи на дроби, текстовой задачи.
- **Английский:** разложение производства формы на шаги. «Перепиши в Present Perfect»: have или has? → третья форма глагола? → всё предложение. Для перевода: ключевая конструкция → порядок слов → всё предложение.
- **Японский:** спряжение: основа → нужная форма → предложение с частицами.

Показанные шаги не дают событий; решаемые — обычные ответы со своими KC и уровнем scaffold в событии.

## 4. Вариация: меняется один параметр

**Серия** — шаг урока или блок планировщика из 3–6 заданий одной семьи, в которых между соседними заданиями меняется ровно один параметр. Ученик видит, что от этого параметра зависит, а что — нет (инвариант).

У заданий семьи есть **измерения** — именованные параметры со значениями: для «since / for» — маркер времени (`since 2019`, `for three years`), подлежащее, утверждение или вопрос. В Nickel семья, построенная функцией, получает измерения автоматически. content-build проверяет, что в семье, заявленной для серий, есть пары заданий, различающиеся ровно одним измерением.

- **Английский:** минимальные пары — «I lived / I have lived here» при одном меняющемся маркере времени; a / the при одном меняющемся контексте (первое упоминание / известно слушателю).
- **Математика:** одно уравнение, меняется только знак коэффициента; одна дробь, меняется только знаменатель.
- **Японский:** одно предложение, меняется только частица.

Серия — для новой KC и для лечения заблуждения. Перемешивание (шаг 6) — после неё: сначала различить, потом выбирать.

## 7. Опровержение заблуждения

У заблуждения может быть **опровержение** — материал, показывающий, где неверная идея ломается. Показывается после диагностированной ошибки вместе с микро-объяснением.

| Предмет | Вид опровержения |
| --- | --- |
| математика | числовой контрпример, вычисленный ядром из ошибочного правила (docs/10, «Ошибочные правила») |
| английский | контрастная пара: два предложения, различающиеся только спорной формой, и чем различается их смысл («I've lost my keys» — ключей нет сейчас; «I lost my keys» — история в прошлом) |
| японский | контрастная пара с разными частицами и разницей в смысле |

Если опровержений у заблуждения несколько, выбор между ними — безопасная развилка для микрорандомизации (docs/11): со временем видно, какое опровержение реже ведёт к повтору ошибки.

## 8. Самообъяснение

**Вопрос «почему?».** Новый вид задания `rule_choice`: после верного ответа ученик выбирает правило, по которому ответил, из 3–4 правил той же темы и её контрастных тем. Варианты — заголовки KC и заблуждений; правильный — primary KC слота. Ответ — обычное событие узнавания для этой KC.

- Показывается не всегда: после верного ответа на новой KC в фазе блока с вероятностью 1/3, и после «верно, сомневаюсь».
- Верный ответ наугад без понимания правила — частый случай у детей; вопрос отделяет его от знания.
- Неверный выбор правила при верном ответе — сигнал «знает форму, не знает правила»: снижается вес наблюдения исходного ответа (как у подсказки, w = 0,5).

**Калибровка уверенности.** Отметки «уверен / сомневаюсь» уже есть. Ученику раз в неделю показывается его калибровка: «когда ты уверен, ты прав в 78% случаев». Это учит замечать собственное незнание — сама по себе полезная привычка, и она делает отметки уверенности точнее для модели.

## 10. Беглые упражнения

Для навыков, где цель — именно автоматизм (таблица умножения, сложение в пределах 20, формы неправильных глаголов, кана), — короткие серии на время: много простых заданий подряд, обратная связь мгновенная. Планировщик даёт их, когда KC освоена по знанию, но τₖ ниже порога автоматизма (docs/03). Это не отдельная игра, а тот же банк заданий с режимом «беглость»: ограничение по времени на задание и без отметки уверенности.

## Чего не делаем

- **Стили обучения** («визуал / аудиал»): гипотеза не подтверждается исследованиями. Представление выбирается по теме и уровню, а не по «типу» ученика.
- **Очки за активность, серии дней, давление** — см. docs/07, «Чего нет».
- **Массированная практика** одной темы до «освоения за один присест»: после блока — перемешивание и интервалы.
- **Перечитывание объяснений как основной способ** — объяснение короткое, дальше извлечение.
