# refl — статистика

Nov 22, 2026 · @Hara

Раздел «Статистика» показывает ученику, что он знает, что забывает и насколько можно верить прогнозам. Сначала короткий итог, глубже — «Расширенно». Эталоны на холсте: LiveStats (итог), StatsDeep (вкладка «Память»).

## Принципы

- **Каждое число — свёртка лога в ядре** (docs/01, docs/03): то же вычисление онлайн и офлайн, без отдельной аналитической базы. У каждого числа есть подсказка «откуда это»: что посчитано, за какой период, из скольких ответов.
- **Прогноз — всегда с интервалом.** Если данных мало, вместо числа — «мало данных» и сколько ещё нужно.
- **Время показывается, но не награждается:** ни ачивок, ни похвалы за минуты в приложении (docs/07).
- **Без сравнения с другими:** нет рейтингов, процентилей и «ты лучше 80% учеников». Статистика видна только владельцу (и ментору, если ученик открыл доступ — docs/01).
- **Компаньон не комментирует пропуски** (docs/06).

## Итог

| Блок | Что показывает | Откуда |
| --- | --- | --- |
| Баннер месяца | одна фраза о главном изменении за месяц | сравнение свёрток на начало и конец месяца |
| Освоено KC | число и прирост | статус KC «освоено» (docs/03) |
| В памяти | средняя вероятность вспомнить по освоенным KC | FSRS-6, R на текущий момент |
| Серия | дни подряд, заморозки | дни с завершённой сессией |
| Время за неделю | минуты | длительности сессий |
| Рост уровня | кривая по неделям, флажки вех | уровень по доменам, `milestone_reached` |
| Радар навыков | 5 навыков сейчас и месяц назад | уровень по доменам |
| Календарь | занятия по дням | сессии |
| Заблуждения | активные, вылеченные за месяц | статусы заблуждений (docs/03) |
| Честность модели | прогноз против факта | калибровка, см. вкладку «Модель» |

## Расширенно

| Вкладка | Что внутри |
| --- | --- |
| Обзор | все блоки итога за выбранный период (неделя, месяц, всё время) |
| Навыки | уровень по доменам и KC каждого домена; что держит уровень главы (самый слабый домен, docs/06) |
| Память | кривые забывания, KC по статусам (новая, освоено, надолго, забывается), прогноз повторений на 7 дней, самые хрупкие KC |
| Словарь | слова по уровням CEFR и статусам, слова к повторению |
| Ошибки | заблуждения: когда появились, сколько держатся, что вылечено; ссылки в тетрадь ошибок |
| Время | время по дням и типам заданий, доля времени на повторения и на новое |
| Модель | калибровка: предсказанная вероятность верного ответа против доли верных, по корзинам; версия модели и весов FSRS (docs/03) |

**Прогноз IELTS** появляется только после полного мока (этап 6) и показывается диапазоном.

## Что закладывается сейчас

Ничего нового в схему событий: все числа считаются из уже существующих событий. Нужна только функция свёртки «статистика за период» в ядре и её типы в сгенерированных TS-типах — на этапе 2.
