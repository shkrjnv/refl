# refl — дизайн-код

Nov 22, 2026 · @Hara

Интерфейс refl должен выглядеть своим, а не шаблонным. Его лицо задают пиксель-арт компаньонов (docs/06) и система тем (docs/07); всё, что ниже, — правила, по которым строится каждый экран.

## Токены

Компоненты используют только семантические токены, никаких «сырых» цветов и размеров в коде. Тема переопределяет весь набор целиком.

| Группа | Что входит |
| --- | --- |
| Цвет | роли: фон, поверхность, текст, приглушённый текст, акцент, верно, неверно, предупреждение, фокус, граница |
| Типографика | шрифт текста, шрифт заголовков, шкала размеров, межстрочный интервал |
| Отступы | шкала на сетке 4 px |
| Форма | радиусы, толщина границ, тени (плоские) |
| Движение | длительности, кривые, частота кадров спрайтов |
| Звук | событие → звук, громкость по умолчанию |
| Пиксели | масштаб спрайтов (только целые ×2/×3/×4) |

Проверка в сборке: в коде интерфейса нет литералов цвета и размеров вне файлов токенов.

## Базовая тема

- **Плоский цвет и ограниченная палитра**, как у пиксель-арта: несколько чистых цветов, без градиентов-переливов.
- **Пиксель — акцент, а не шрифт текста.** Пиксельные иконки, рамки, компаньоны; основной текст — хорошо читаемый шрифт.
- **Свой набор пиксельных иконок 16×16** в одном стиле с компаньонами; никаких эмодзи вместо иконок.
- **Спокойный экран задания:** одно главное действие, компаньон неподвижен во время ответа (docs/06).
- **Mobile-first:** слабые телефоны, одна колонка, крупные зоны нажатия.

## Шрифты

- Полная кириллица, латиница и узбекская латиница с ʻ (U+02BB) в oʻ, gʻ и ’ (U+2019).
- Символы IPA для произношения: ə θ ð ŋ ʃ ʒ ɪ ʊ æ ɜ ɒ ʌ ː ˈ ˌ.
- Шрифты хранятся у нас и отдаются вместе с PWA (офлайн), без внешних сервисов шрифтов.
- Проверка в сборке: каждый шрифт каждой темы покрывает этот набор символов. Выбор шрифта начинается с этой проверки, а не с внешнего вида.

## Чего не делать

Список для ревью каждого экрана. Всё это — узнаваемые признаки сгенерированного интерфейса:

- фиолетово-синие градиенты, градиентный текст, «стекло» (blur-панели);
- одинаковые скруглённые карточки с мягкой тенью на каждом экране;
- эмодзи и «искорки» как иконки, стоковые иллюстрации;
- центрированный «герой» с крупным заголовком и кнопкой;
- пустые фразы в интерфейсе («Unlock your potential», «Раскрой свой потенциал»): текст говорит, что произошло и что делать дальше;
- анимация ради анимации.

## Обратная связь, движение, звук

- **Верно / неверно — не только цветом:** всегда иконка и текст (дальтонизм).
- **Движение:** интерфейс ≤ 200 мс; праздничные анимации — только на вехах и ачивках; спрайты — ступенчато, с фиксированной частотой кадров, без сглаживания (`image-rendering: pixelated`). Системная настройка «уменьшить движение» соблюдается.
- **Звук:** короткие звуки на событиях (верно, неверно — мягко, веха), тихие по умолчанию, выключаются одной настройкой; ошибка никогда не звучит резко.

## Доступность и языки

- Контраст не ниже WCAG AA в каждой теме; проверяется в сборке пакета темы (docs/07).
- Зоны нажатия ≥ 44 px; интерфейс выдерживает увеличение шрифта системой.
- Узбекские строки обычно длиннее: вёрстка не рассчитывает на длину английского текста; текста внутри картинок нет.

## Процесс

Перед первым экраном этапа 1 делается базовая тема: токены, шрифт (после проверки покрытия), иконки и один эталонный экран задания. Каждый новый экран сверяется со списком «Чего не делать».
