# Design reference

Artboards from the design canvas "refl — направления дизайна", designed together with the author. They are the visual reference for the prototype (docs/15) until the design code in docs/08 is revised.

These files are exports of the canvas source: they use the canvas runtime (`support.js`, `<x-dc>`), so they do not render standalone. Read them for markup, styles, tokens and motion, or open the canvas itself to see them rendered.

| File | What |
| --- | --- |
| `LiveToday.html` | "Today" screen, desktop — the base of the "Living Studio" style |
| `LiveMobile.html` | "Today" screen, mobile |
| `LiveStats.html` | statistics summary |
| `StatsDeep.html` | statistics, "Memory" tab |
| `ProfileMe.html`, `ProfileOther.html` | own and someone else's profile |
| `Frames.html` | tier frames |
| `ProfileV2.html`, `Wardrobe.html`, `Achievements.html`, `Deck.html` | profile v2, fitting room, achievements, card deck |
| `canvas.json` | canvas layout and notes |

Tokens: INK `#14213d`, BG `#f3f5fa`, BLUE `#2f6bff`, SUN `#ff9f43`, GREEN `#22b07d`, CORAL `#ff6b6b`, PURP `#7c5cff`; font Geologica; gradients only inside illustrations.
